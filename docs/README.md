# DailyMoneyApp

**DailyMoneyApp** — iOS-приложение для учёта ежедневных расходов и контроля бюджета в RSD.

## Что делает приложение

Приложение помогает быстро записывать траты и понимать, сколько денег можно потратить сегодня.

- **Дневной бюджет** — рассчитывается автоматически каждый день в 6:00 на основе месячного лимита, уже потраченной суммы и оставшихся дней в месяце.
- **Быстрый ввод расходов** — сумма и категория (продукты, доставка, транспорт и др.) с минимальным числом действий.
- **Остаток на сегодня** — на главном экране показывается доступная сумма; цвет подсказывает, насколько близко к лимиту.
- **Журнал транзакций** — список трат за текущий месяц с группировкой по дням, удалением записей и экспортом в CSV.
- **Настройки бюджета** — можно задать месячный лимит в RSD.
- **Интеграция с Google Forms** — при настройке URL каждая трата дополнительно отправляется в форму.
- **Локальное хранение** — транзакции сохраняются на устройстве в CSV-кэше.

## Технологии

- SwiftUI
- iOS
- Локальное хранение через `UserDefaults` и файловый кэш
